software meant to outlast the hype cycle, and I run my own.

Days go to healthcare claims infrastructure in Go, GraphQL, and React,
the kind of systems where a quiet bug costs real money, so they don't
get to have them. Before healthcare I led a payments platform off

RAG, and agents, the engineering around models rather than the hype. The

taught it to, and tools that keep my data mine.
