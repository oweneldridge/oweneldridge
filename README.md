# Owen Eldridge

Full-stack engineer working on money in regulated industries: payments
infrastructure, and now pharmacy claims. Most of my work is about
correctness in money and claims data. I establish what the data supports,
find where it stopped being true, and say clearly what hasn't been
measured yet.

At work that's Go, TypeScript, and a lot of SQL. Outside it I run a
homelab and build local-first tools.

Case studies and a resume: **[oweneldridge.io](https://oweneldridge.io)**

## Building

- [Basalt](https://github.com/oweneldridge/basalt): an open-source,
  local-first Markdown knowledge base that stays compatible with Obsidian
  vaults. Tauri 2, React, CodeMirror 6.
- [The site itself](https://github.com/oweneldridge/oweneldridge.io):
  plain HTML and CSS, under 100 KB, no JavaScript beyond the theme switch.
  Source of truth on [Codeberg](https://codeberg.org/oweneldridge/oweneldridge.io).
- [A local audiobook pipeline](https://github.com/oweneldridge/audiobook-creator-tts):
  ebooks in, chaptered .m4b audiobooks out, narrated by Kokoro on my own server.
- [audiobook.koplugin](https://github.com/oweneldridge/audiobook.koplugin):
  .m4b playback in KOReader on a Kobo, with Bluetooth brought up from a
  cold boot. A paused proof of concept.
